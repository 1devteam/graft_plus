# G.R.A.F.T.+ assurance model

The pack separates artifact integrity, canonical identity, structural coverage, architectural reconstruction, change evidence, proof readiness, execution authority, and merge authority. A single scalar disposition is only a compatibility summary and must not substitute for these independent propositions.

This model is derived from the Chromium stress evidence: ingestion scale, semantic fidelity, identity integrity, coverage, proof, and authority are distinct truths.
